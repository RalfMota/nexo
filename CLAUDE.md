## Agent skills

### Issue tracker

Issues e specs ficam como arquivos markdown em `.scratch/<funcionalidade>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Os cinco rótulos padrão (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), gravados numa linha `Status:` de cada issue. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: um `GLOSSARY.md` e `docs/adr/` na raiz do repositório. See `docs/agents/domain.md`.
